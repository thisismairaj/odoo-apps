# Odoo apps by Softstribe Ventures

Small Odoo modules, one folder per module. The branch name is the Odoo version (`18.0`, `19.0`, `20.0`).

| Module | What it does |
|---|---|
| `mrj_website_ask_ai` | Ask AI About This Product: a button on eCommerce product pages that opens the shopper's own AI assistant (ChatGPT, Perplexity, Claude, Gemini, Grok) with the product link and a buying question filled in. |
| `mrj_calendly_sync` | Calendly Bookings to Calendar: brings Calendly bookings into the Odoo Calendar (invitees as contacts, meeting link, answers, cancellations). Works with Calendly's free plan. |
| `mrj_website_sales_proof` | Honest Sales Popup: a small social proof card for the eCommerce shop that shows only real recent orders, real views today and your own trust messages. |
| `mrj_web_dark_mode` | Dark Mode for Community: a dark backend theme for Odoo Community, switched on per user from the user menu. |
| `mrj_crm_meta_leads` | Facebook and Instagram Lead Ads to CRM: imports leads from Meta instant forms into Odoo CRM every 15 minutes or by webhook, with campaign, ad set and ad, per-form team and tags, and no duplicates. |
